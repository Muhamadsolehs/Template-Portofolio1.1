# Portfolio - Muhamad Soleh S

Modern, high-performance portfolio landing page featuring a Framer-inspired sunset glow aesthetic, dark mode, smooth interactions, and responsive design.

## Features
- **Sunset Hero Section**: Cinematic sunset lighting with custom rim-light portrait and embedded navigation.
- **Brand Showcase**: "Trusted by Brands I've Helped Shape" logo bar.
- **Editorial Philosophy**: "Behind the Designs" two-column presentation.
- **Featured Works**: 3-card vertical showcase gallery matching modern editorial standards.
- **Selected Case Studies**: 6 project cards with category filter tabs (*All, E-Commerce, Web Design, UI/UX & SaaS*) and 3D perspective tilt on hover.
- **Services & Capabilities**: 4 specialized offerings with interactive micro-animations.
- **Work Process**: 5-step structured process chain with quote highlight card.
- **Testimonials**: Authentic reviews with 5-star ratings.
- **Contact & Inquiry**: Integrated message form, click-to-copy contact channels, and Jakarta timezone.
- **Full Navigation Footer**: Quick "Back to Top" button, section links, and social profile shortcuts.

## Tech Stack
- HTML5 (Semantic & Accessible)
- Vanilla CSS3 (Custom Properties, Flexbox, Grid, Glassmorphism)
- Vanilla JavaScript (Micro-interactions, Toast, Filtering, Tilt)

## Usage
Simply open `index.html` in any modern web browser or serve via a local web server (e.g. Laragon, Live Server, or `python -m http.server`).
